# DecoVision - Starter Project

## Overview
DecoVision is a web app to upload room images and visualize interiors with furniture, colors, and layouts.

This starter repo contains:
- **frontend/** React app
- **backend/** Node.js Express API

## Run Locally

### Backend
```bash
cd backend
npm install
npm start
```
Runs on http://localhost:4000

### Frontend
```bash
cd frontend
npm install
npm start
```
Runs on http://localhost:3000
